## Features

* **GUI:** That project has graphical interface. This created using QT framework.
* **Multiple algorithms:** The application can generate hashes using a wide range of hashing algorithms, including md5, SHA1, SHA224, SHA256, SHA382, and SHA512.
* **Adjustable length:** You can chose lenght of generated hash.

> [!NOTE]
> That program was created many years ago, and due to lack of qualifications has bad name. Therefore name must be HashesGenerator, or something like that.

> [!CAUTION]
> Also that program has bugs and other problems, but it repository must be preserved in terms of memory and the point from which we all started.

## Getting Started :seedling:

If you want to start that application, you may go through basic steps for Python "pet projects".

### Prerequisites :page_with_curl:

All you need installed on your machine is Python 3.

### Installation :inbox_tray:

To start the project, follow these steps:

1. Clone this repository to your local machine:
   ```bash
    git clone https://github.com/OgrallSerebroust/PasswordGenerator.git
    ```
2. Navigate to the project directory:
    ```bash
    cd PasswordGenerator
    ```
3. Install the dependencies(all you need is PyQt5). Before it don't remember to activate or create and activate venv:
    ```bash
    pip install PyQt5
    ```
4. Run project. Startpoint is **main.py**.
